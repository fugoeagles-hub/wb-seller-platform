# postgres-rls-multitenant

Учебный пример изоляции данных клиентов в одной базе PostgreSQL средствами Row-Level Security. Написан с нуля для портфолио.

**Задача.** Одна база обслуживает много клиентов. Ошибка в одном `WHERE` в коде не должна открыть чужие данные, поэтому изоляцию держит сама база.

**Что внутри:**
- политики RLS с `FORCE ROW LEVEL SECURITY`;
- роль приложения без права обхода RLS;
- контекст клиента ставится на транзакцию: без него видно 0 строк;
- права пользователей ключами в JSONB, роль задаёт набор прав по умолчанию.

**Запуск** (нужны Docker и Python 3.11+):
```
pip install "psycopg[binary]" pytest
./scripts/run_tests.sh
```
Скрипт поднимает `postgres:16` на свободном порту, прогоняет тесты и удаляет контейнер.
